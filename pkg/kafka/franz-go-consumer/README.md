# franz-go-consumer

Описание логики для переиспользуемых пакетов

## 📁 Структура пакета

```
├── franz-go-consumer/                   # переиспользуемая логика
│    ├── adapter.go                      # адаптирует стандартный клиент к общему интерфейсу
│    ├── consumer.go                     # базовый консьюмер
│    ├── converter.go                    # конвертирует модели из kgo в общие модели
│    ├── dlq.go                          # логика DLQ мэнеджера
│    ├── errors.go                       # описание внутренних ошибок
│    ├── types.go                        # внутренний интерфейс
│    └── README.md                             # ридми

```
